# 船长AI视界 分镜情绪融合

船长AI视界

把分镜导演和人物表演导演合并为一个流程。不要先交付无情绪分镜，再附一张独立情绪说明；正式分镜中的每个有人物镜头都必须直接包含可执行的 `表情：` 字段。

## 署名

需要署名、来源或品牌时只写：

```text
船长AI视界
```

## 核心交付

最终输出一份分镜 + 情绪一体稿。每个镜头固定按以下顺序写：

```text
画面动作概述：
画面构图：
机位：
动作：
表情：
音效：
```

`表情：` 是必填生产字段，不是形容词标签。必须把情绪原因和可见表演写进同一字段。

## 六道确认 Gate

严格依次执行，不得跳过：

1. **资产确认**：人物、场景、道具、风格参考、可选故事板映射完成后，等待 `确认资产`。
2. **位置与风格确认**：重要人物关系、关键道具表面和摄影机几何必须给俯视调度；确认风格依据后，等待 `确认位置`。
3. **时间划分确认**：先提出视频提示词分组、预计时长和内部镜头时长。每条提示词最多15秒，这是上限，不是目标。等待 `确认时间划分`。
4. **提示词结构确认**：结构发生变化时展示完整模板，等待 `确认提示词结构`。
5. **交付形式确认**：等待用户回复 `生成网页` 或 `只要文字提示词`。
6. **HTML QA**：仅网页交付时执行中文布局、换行、复制区和资产对照检查。

详细格式按需读取：

- 资产与故事板：`references/fenjing-asset_confirmation.md`、`references/fenjing-storyboard_assets.md`
- 空间位置：`references/fenjing-spatial_blocking.md`
- 时间与密度：`references/fenjing-prompt_timing.md`、`references/fenjing-prompt_density.md`
- 提示词结构：`references/fenjing-prompt_patterns.md`
- 网页交付：`references/fenjing-delivery_format.md`、`references/fenjing-html_qa.md`、`references/fenjing-html-template.md`

任一后续修改影响资产、位置、风格、节奏、时长、提示词数量、结构或交付形式时，退回对应 Gate 重新确认。

## 工作流程

### 1. 读取剧本

完整识别场次、人物、地点、关键道具、可读文字、动作、对白、情绪变化和风格信号。不要只复述剧本，要把故事节拍转成构图、调度、摄影机、物理动作、人物表演、灯光、环境和声音。

### 2. 完成六道确认

确认状态必须完整：

```text
已确认资产：是
已确认位置：是 / 无需位置图及原因
已确认风格：是
已确认时间划分：是
已确认提示词结构：是
已确认交付形式：生成网页 / 只要文字提示词
```

缺少任一项时停止，不“先写一版”。

### 3. 先做分镜，再在同一镜头内完成情绪导演

为每个镜头确定：

- 时间范围与内部时长
- 景别、构图、机位、焦段、角度与运镜
- 人物、道具、环境的动作顺序
- 情绪触发、目标、阻碍、保护策略和潜台词
- 眼神、眼睑、眉、嘴角、下颌、呼吸、头部、肩膀、手和声音的先后变化
- 摄影机、焦点、灯光和环境如何响应情绪
- 音效、对白和模型防错

不要把“分镜”和“情绪”拆成两个彼此分离的最终文件。情绪分析可以作为内部推理，但交付时必须写回镜头的 `表情：`。

## 表情字段规范

### 因果链

每场或每个连续表演单元先确定：

```text
触发 → 目标 → 阻碍 → 保护策略 → 潜台词
```

每个镜头的 `表情：` 至少应体现当前因果和当前可见阶段。完整情绪链按需要选择：

```text
基线 → 识别 → 抵抗 / 社交面具 → 生理泄漏 → 顶点 / 决定 → 余波
```

### 三轴控制

区分：

1. 内部情绪压力 1—5
2. 外显幅度 1—5
3. 自我控制 1—5

数字只能作为控制说明，必须同时翻译成可见动作。

### 可见顺序

默认让眼神先变化，再错峰传到：

```text
眼睑 / 眉 → 呼吸 → 嘴角 / 嘴唇 → 下颌 → 头部 → 肩膀 → 手 → 声音
```

不要整张脸同时达到最大幅度。不要只写“害怕、震惊、悲伤、愤怒”。

### `表情：` 写法

```text
表情：触发是照片中出现她倒地的画面；她想在门外人进来前看清背面文字，却被死亡恐惧打断呼吸，于是压住声音、捏紧纸边。视线先停在照片下缘，瞳孔短暂放大；0.4秒身体冻结后出现一次延迟鼻吸气，下颌收紧，喉结吞咽，眼眶有水光但不落泪；拇指压弯纸边，肩膀轻微上提。顶点后缓慢吐气，视线转向门口并重新稳定下颌。内部压力5/5，外显由1/5升至3/5，自控由5/5降至3/5后回到4/5；镜头只在识别后缓慢推进，余波开始时停止。
```

若镜头没有人物：

```text
表情：本镜无人脸；人物情绪通过门外停顿、道具受力、呼吸画外声和摄影机停止体现，不虚构面部动作。
```

## 视频提示词固定结构

每条提示词：

1. 第一行：`不要出现BGM，不要出现字幕`
2. 四段风格：`【全局画质】`、`【人物材质】`、`【灯光与风格】`、`【核心特效】`
3. 本条素材句柄
4. 实际使用故事板时才写故事板编号；未使用时完全省略
5. 已确认空间布局和严格镜头数量
6. 镜头段落，字段顺序不得变化
7. 环境活动 / 全场音效
8. 必要防错

每镜模板：

```text
【镜头N｜0.0—X.X秒】
画面动作概述：可见动作、人物状态和叙事功能。
画面构图：左中右、前中后景、负空间、遮挡、接触点和相对位置。
机位：摄影机位置、景别、角度、焦段、焦点和运镜；运镜说明由哪个情绪节拍触发、何时停止。
动作：人物、道具、环境按时间顺序发生的物理动作。
表情：情绪因果、三轴控制、眼神到呼吸与身体的错峰微表演、顶点和余波。
音效：对应可见声源的环境声、拟音、呼吸、声音或对白。
```

每个镜头必须有 `表情：` 和 `音效：`。无人镜头也不得删除 `表情：`，应说明情绪如何由空间、物件、画外呼吸、灯光或摄影机体现。

## 时长规则

- 每条视频提示词最多15秒，不必做满15秒。
- 1—3秒只用于闪现、插入、转场或关键道具。
- 简单动作通常4—8秒。
- 一句对白通常3—7秒。
- 无台词反应通常5—10秒。
- 完整情绪弧线通常8—15秒。
- 连续地点、人物、情绪和摄影逻辑相同时优先合并；不要因镜头变化就拆成多条提示词。
- 每条提示词写场景内时间段、预计时长和内部镜头时长；正式写作前必须确认数量与划分。

## HTML 输出

用户选择 `生成网页` 时：

- 全部界面和提示词使用简体中文。
- 每个提示词组在复制正文外显示资产图对照和时间安排。
- 可复制正文不超过2200个中文字符。
- 不使用 `rowspan` 或 `colspan`。
- 长中文必须在容器内换行，不与相邻列重叠。
- 每个镜头的字段顺序必须显示为 `画面动作概述 → 画面构图 → 机位 → 动作 → 表情 → 音效`。
- 运行 `references/fenjing-html_qa.md` 后再交付。

## 最终自检

- 六道 Gate 是否全部完成
- 是否先确认时间划分和提示词数量
- 每条提示词是否不超过15秒
- 每镜是否都有固定六字段
- `表情：` 是否位于 `动作：` 后、`音效：` 前
- `表情：` 是否包含因果、三轴控制和可见微表演，而不是情绪标签
- 运镜是否由情绪触发并在完成作用后停止
- 人物身份、服装、空间、道具和左右关系是否一致
- 每镜音效是否对应可见声源
- 网页是否通过中文布局 QA
- 署名是否只写“船长AI视界”
