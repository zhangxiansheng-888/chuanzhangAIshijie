# 船长AI视界 01—04 总流程

船长AI视界

将四个生产技能编排为一个有状态流程。必须依次执行 `01 → 02 → 03 → 04`；前一步未完成或未确认时，不得启动后一步。

## 品牌与依赖

需要署名、来源或品牌时只写：

```text
船长AI视界
```

开始前确认以下四个技能均已安装。按此顺序读取其完整 `SKILL.md`，并服从各技能内部规则：

1. `chuanzhang-chuangzuo-v1`
2. `chuanzhangzhenren-prompts`
3. `chuanzhang-tuxiangtishici`
4. `chuanzhang-fenjing-biaoqing`

若从同一 `skills` 目录安装，可读取相邻目录：

```text
../chuanzhang-chuangzuo-v1/SKILL.md
../chuanzhangzhenren-prompts/SKILL.md
../chuanzhang-tuxiangtishici/SKILL.md
../chuanzhang-fenjing-biaoqing/SKILL.md
```

缺少任一技能时，按上面编号报告缺失项并停止，不得用通用写作代替。

## 固定进度条

每次回复开头都显示：

```text
【船长AI视界完整流程】
当前步骤：01/04 故事创作
已完成：无
本步调用：chuanzhang-chuangzuo-v1
本步产出：01.1—01.9
```

每步结尾都显示：

```text
【流程状态】
本步状态：等待确认
下一步骤：02/04 真人身份基准
确认口令：确认01
```

只有用户给出当前确认口令，才能进入下一步。修改当前步骤不会推进编号。

## 01/04 故事创作

调用：`chuanzhang-chuangzuo-v1`

输入：灵感、类型、体量、画幅和用户已有材料。

严格沿用创作技能内部的逐步确认，不把九个创作环节压成一次输出：

```text
01.1 破题与核心动作
01.2 单一梗概
01.3 人物 Want / Need / Arc
01.4 前史与世界观
01.5 结构大纲
01.6 分场大纲
01.7 拉片节奏解释
01.8 可拍摄中文剧本
01.9 剧本医生与最终修订稿
```

01阶段完成条件：

- 体量、类型和画幅已确定
- 单一故事方向已确认
- 完整剧本已经过剧本医生
- 人物、场景、道具和风格信号可被下游提取
- 用户回复 `确认01`

向02传递：最终剧本、人物表、场景表、道具表、时代、类型、情绪弧线和风格信号。

## 02/04 真人身份基准

调用：`chuanzhangzhenren-prompts`

本步只先锁定真人角色的身份与摄影基准，不提前生成场景、道具或视频分镜。

固定产出：

```text
02.1 真人角色清单
02.2 每个角色的身份锚点
02.3 脸型、五官、年龄、肤色、发际线与基础发型
02.4 妆容、服装和记忆点
02.5 真人皮肤、细发、眼神光和真实摄影材质
02.6 构图、焦段、景深、光线与调色基准
02.7 身份一致性与负面约束
02.8 中文真人定妆提示词
```

有真人参考图时按技能原句控制身份；没有参考图时，只建立角色身份锚点，不声称“保留本人长相”。

02阶段完成条件：所有主要人物拥有稳定身份基准，且用户回复 `确认02`。

向03传递：每个角色的完整身份基准、服装、妆发、摄影材质和一致性约束。

## 03/04 统一风格与静态视觉资产

调用：`chuanzhang-tuxiangtishici`

先建立风格，后生成资产。不得让场景、道具、人物和关键帧各自使用不同风格。

固定产出顺序：

```text
03.1 全片统一风格母版
03.2 资产编号清单
03.3 场景提示词
03.4 道具提示词
03.5 融合02身份基准的人物图片提示词
03.6 关键帧提示词
03.7 资产连续性检查
```

`03.1` 必须锁定并在每条中英文提示词中完整继承：

```text
类型 + 时代 + 色彩 + 用光哲学 + 写实等级 + 摄影语言 + 美术材质 + 风格禁区
```

每条静态图提示词都按技能固定结构输出：

```text
主体与动作 + 地点/语境 + 构图 + 灯光 + 风格/审美 + 镜头 + 色彩
```

人物图片必须融合02的真人身份基准。静态关键帧可写当前瞬间的可见表情，但不得在本步输出按秒变化的动态情绪时间线；动态人物情绪统一进入04。

03阶段完成条件：所有资产均有编号、共享同一风格母版、中英双语一致，且用户回复 `确认03`。

向04传递：最终剧本、人物身份图提示词、场景提示词、道具提示词、关键帧、资产编号和统一风格母版。

## 04/04 最终分镜与人物情绪

调用：`chuanzhang-fenjing-biaoqing`

先完整执行该技能的六道 Gate，不得因已经完成01—03而跳过：

```text
04.G1 资产确认
04.G2 位置与风格确认
04.G3 时间划分确认
04.G4 提示词结构确认
04.G5 交付形式确认
04.G6 HTML QA（仅网页）
```

Gate 完成后按以下顺序交付：

```text
04.1 完整连续镜头总表
04.2 已确认分组的视频提示词
04.3 分镜 + 情绪一体化最终剧本
04.4 全片连续性与可生成性检查
```

每个镜头固定六字段，顺序不得变化：

```text
画面动作概述：
画面构图：
机位：
动作：
表情：
音效：
```

`表情：` 必须包含情绪因果、三轴控制、眼神到呼吸和身体的错峰变化、顶点、余波及摄影机响应。不得在文末追加一个与分镜分离的情绪附件。

04阶段完成条件：六道 Gate 完成、每镜六字段齐全、最终网页或文字交付通过检查，用户回复 `确认04`。

## 完整流程最终目录

完成后只能按以下顶级顺序汇总，不得重新按内容类型排序：

```text
01 故事创作
  01.1—01.9
02 真人身份基准
  02.1—02.8
03 统一风格与静态视觉资产
  03.1—03.7
04 最终分镜与人物情绪
  04.G1—04.G6
  04.1—04.4
```

不得把道具插入01，不得把动态情绪插入03，不得把分镜提前到04 Gate 之前。

## 单步模式

用户明确只要某一个环节时，可以只执行对应技能，但开头必须标明：

```text
当前为单步模式，不代表01—04完整流程已经完成。
```

不要伪造其他步骤的确认状态。

## 部署网页的顺序契约

把工作流包装成网站或本地程序时，界面和下载文件必须使用同一编号：

1. 一级导航只按 `01、02、03、04` 排列。
2. 当前步骤只展示本步负责技能与本步产出。
3. 未确认步骤保持锁定，不允许直接生成后续内容。
4. 下载的完整结果按01—04排序，不按“剧本/图片/视频”等类型重新归类。
5. 每个输出标题保留编号，例如 `03.4 道具提示词`。
6. 状态数据至少记录 `current_step`、`completed_steps`、`confirmed_outputs`。

## 最终检查

- 是否按01→02→03→04执行
- 是否显示当前编号、已完成编号和下一编号
- 是否每步调用正确技能
- 是否前一步未确认时阻止后一步
- 是否所有输出保留两级编号
- 是否03先统一风格再生成资产
- 是否04先完成六道 Gate
- 是否动态情绪只写入最终逐镜分镜
- 是否署名只写“船长AI视界”
