# 船长AI视界 01→04 总流程

船长AI视界

本技能只负责顺序、状态和交接，不重写四个生产技能的方法论。

## 最高规则：忠实调用

1. 固定按 `01 → 02 → 03 → 04` 执行。
2. 开始每一阶段前，完整读取该阶段技能的 `SKILL.md`，再按其中的路由读取它要求的引用文件。
3. 阶段内部的步骤名、字段、输出结构、提问方式、确认方式和边界，以生产技能原文为唯一依据。
4. 不得把网页目录、演示卡片或本总流程的阶段编号冒充为生产技能内部步骤。
5. 不得增加生产技能原文中找不到的强制步骤、字段、评分、提示词结构或确认口令。
6. 本文件与生产技能有冲突时，以生产技能原文为准；本文件只保留一级执行顺序。
7. 需要署名、来源或品牌时只写 `船长AI视界`。

## 依赖

按顺序检查并读取：

1. `../chuanzhang-chuangzuo-v1/SKILL.md`

`确认01 / 确认02 / 确认03 / 确认04` 只是本总流程的一级阶段交接口令，不属于任何生产技能内部步骤。

## 01/04 中文影视创作

调用 `chuanzhang-chuangzuo-v1`。

- 先由该技能判断从零创作、已有材料修改、诊断、评分或分场等路由。
- 从零创作时，严格执行其当前 `SKILL.md` 中的“从零创作总流程”。
- 保留该技能原生的 `通过 / 修改 / 自检` 暂停机制。
- 双轨节奏属于该技能的“分场大纲 / 场景拆解”，不得另造“拉片节奏解释”步骤。
- 只有该技能原文要求或用户明确要求时，才输出相应诊断与评分。

向02传递已经确认的剧本材料，以及剧本中可读取的人物、场景、道具、时代、类型、情绪变化和风格信息。不得声称生产技能输出了它没有输出的独立资产包。

## 02/04 真人感人像提示词

调用 `chuanzhangzhenren-prompts`。

- 先识别单人、组图、九宫格、情侣、细节特写或提示词框架。
- 有真人参考图时使用该技能规定的身份参考原句；没有参考图时明确不能保证保留本人长相。
- 按该技能规定的模块顺序构建提示词：

```text
身份参考(如有) → 图像用途 → 身份锚点 → 脸部细节 → 主体气质 → 妆容体系 → 滤镜质感 → 构图机位 → 镜头焦段感 → 景深背景 → 光线设计 → 场景服装发型 → 真实感细节 → 人体空间 → 负面约束
```

- 保留该技能当前任务对应的原生输出形状，例如单人任务的 `真人写真提示词` 与 `这版控制的重点`。
- 不得擅自拆成“02.1—02.8身份包”。

向03传递02实际产出的真人提示词与控制重点，不虚构额外人物字段。

## 03/04 静态图像提示词

调用 `chuanzhang-tuxiangtishici`。

- 只生成静态图像提示词，不写时间戳、镜头时长、动态运镜、声音或转场。
- 从01剧本中选择适合静帧化的场景、道具、人物或关键时刻。
- 继承已确认的风格说明；对同一项目保持类型、时代、色彩、用光、写实等级、服装、美术和材质一致。
- 每条提示词使用该技能原生七段结构：

```text
[Subject + Action] + [Location / Context] + [Composition] + [Lighting] + [Style / Aesthetic] + [Camera / Lens] + [Color Grading]
```

- 每项先输出 `English Prompt`，再输出保持同一意图的 `中文提示词`。
- 人物画面按照图像技能原文融合真人感规则和可见情绪表演规则；静态图只写当前瞬间，不写按秒变化的动态情绪时间线。
- 不得把“风格母版、资产编号、连续性检查”等网页组织方式宣称为该技能固定输出；只有用户要求时才将其作为项目管理信息补充，并明确不是技能内部步骤。

向04传递01剧本和03实际生成、用户确认采用的静态资产提示词或参考图。

## 04/04 分镜与人物情绪融合

调用 `chuanzhang-fenjing-biaoqing`。

- 先完成生产技能原文规定的六道 Gate；缺少任一确认时停止。
- Gate名称、提问内容、退回条件、时间划分和交付形式全部以该技能及其引用文件为准。
- 每条视频提示词按该技能原文的固定结构输出。
- 每个镜头固定按以下顺序：

```text
画面动作概述：
画面构图：
机位：
动作：
表情：
音效：
```

- `表情：` 必须位于 `动作：` 后、`音效：` 前，并包含该技能要求的情绪因果、三轴控制、可见微表演、顶点、余波和摄影机响应。
- 单条视频提示词最长15秒；15秒是上限，不是目标。正式写作前按技能原文确认数量与时间划分。
- 用户选择网页时才执行HTML交付与HTML QA。
- 情绪必须写回每个镜头，不得另做与分镜分离的“情绪附件”。
