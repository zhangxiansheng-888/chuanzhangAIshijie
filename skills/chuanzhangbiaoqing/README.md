# chuanzhangbiaoqing Skill

> 把“她很伤心”“他先震惊再愤怒”升级成有动机、有递进、有微表情、有镜头配合的完整人物表演。

一个专门为 AI 视频人物表演设计的提示词 Skill。

它会先理解人物为什么产生反应，再把情绪拆成眼神、眼睑、眉间、嘴角、下颌、呼吸、姿态和声音的连续变化。面对一句模糊描述，它还会补全成年角色、场景、戏剧动机、镜头、光线、声音、准确时长和负面约束，输出可以直接复制到视频模型中的完整提示词。

## 效果示例

### 暗恋对象走来

用户输入：

```text
现代职场女性，看到自己暗恋的同事走过来
```

Skill 会先建立表演动机：

```text
触发事件：她发现暗恋的同事正朝自己走来。
当前目标：表现自然，同时希望对方注意到自己。
现实障碍：办公室里还有其他同事，她害怕自己的喜欢被看出来。
保护策略：低头整理文件，用工作动作掩饰心动。
隐藏潜台词：自然一点，别让他发现我一直在注意他。
```

随后选择能够容纳表演节拍的时长，并生成精确时间轴：

```text
总时长6秒。

0.0至1.0秒：她低头整理文件，呼吸平稳，建立普通工作状态。
1.0至2.0秒：余光认出对方，视线停住半拍，呼吸短暂停顿。
2.0至3.2秒：她低头掩饰，把已经整齐的文件再次对齐，嘴角压住笑意。
3.2至4.8秒：脚步靠近，她重新抬眼，短暂躲开视线后再次看向对方。
4.8至6.0秒：两人短暂对视，她再次低头，留下没有完全藏住的浅笑。
```

生成重点落在情绪泄露的过程，眼神先变化，嘴角稍后跟随，呼吸和手部动作继续提供真实感。

### 帝王暗下狠心

用户输入：

```text
一位帝王，脸部特写。从震惊到从容，再到暗自下了狠心
```

Skill 会补充一个能够支撑情绪转折的触发事件：帝王从密奏中确认最信任的皇子伪造诏令、秘密调兵。

它不会把“狠心”写成夸张邪笑，而会使用可拍摄的动作完成表达：

```text
震惊：视线停住，上眼睑抬起，吸入半口气后屏住。
从容：缓慢呼气，嘴唇闭合，眉间恢复平直，重新抬起目光。
狠心：视线稳定锁定心腹侍卫，下眼睑收紧，下颌绷紧半拍，将密奏推向对方。
```

最终的狠意来自人物已经完成决定，外在仍然保留帝王的自制与威仪。

## 它解决什么

很多人物视频提示词只写情绪名称，模型只能调用通用表情模板，结果容易出现这些问题：

* 情绪突然达到最大强度，缺少反应过程
* 眼睛、眉毛、嘴巴和身体同时变化，表演像预设动画
* 悲伤只剩落泪，愤怒只剩瞪眼，害羞只剩低头微笑
* 人物缺少行为动机，动作与情绪之间没有因果关系
* 镜头只负责拍脸，没有帮助观众理解人物心理
* 每段视频机械使用同一时长，复杂情绪被压缩，简单反应被拖长
* 角色在生成过程中换脸、换年龄、换发型或换服装
* 声音、呼吸、道具动作和画面彼此脱节

这个 Skill 会把人物表演组织成一条可执行的因果链：

```text
触发事件 → 当前目标 → 现实障碍 → 保护策略 → 认出事实 → 抵抗情绪 → 情绪泄露 → 情绪顶点 → 情绪余韵 → 镜头与环境响应
```

## 适合什么场景

* Seedance、Sora、Kling、Runway、Veo 等文生视频与图生视频模型
* 人物特写、情绪反应、微表情、对话表演和关系戏
* 古装权谋、现代职场、爱情、家庭、悬疑和剧情短片
* 把一句模糊描述扩展成完整 AI 视频提示词
* 为已有场景补充一段可直接插入的人物表演指令
* 分析现有视频或提示词中的表演问题并进行改写

## 工作原理

### 1. 先写动机

Skill 会先确定五个问题：

1. 人物刚刚看见或听见了什么
2. 人物此刻最想得到什么
3. 什么阻止人物直接行动
4. 人物准备用什么方式保护自己
5. 人物心里有什么话不能说出口

这五项决定后续的视线、呼吸、面部动作、身体姿态和镜头位置。

### 2. 用三条轴控制表演

同一个情绪可以拥有完全不同的外在表现。Skill 会分别控制：

1. 内在情绪压力
2. 外在表达幅度
3. 自我控制程度

例如，一个人内心压力达到5/5，外在表达只有1/5，自我控制保持5/5。画面可以表现为视线短暂失焦、下颌轻微收紧、呼吸变浅，而不需要大哭或怒吼。

数字只用于控制方向。最终提示词会把它们翻译成清晰可见的表演动作。

### 3. 让情绪逐步发生

人物通常先通过眼神确认信息，随后影响眼睑和眉间，再传递到嘴角、下颌、呼吸、肩膀、双手和声音。

Skill 会根据剧情选择需要的阶段：

```text
日常状态
发现触发事件
尝试维持原有表情
呼吸或眼神泄露情绪
面部与身体进一步变化
说出话、作出决定或失去控制
保留变化后的情绪余韵
```

### 4. 根据实际节拍选择时长

Skill 没有固定默认时长。它会先计算必须看见的表演节拍，再选择能够自然容纳这些节拍的最短时长。

* 单一微表情通常需要约3至4秒
* 认出、掩饰和余韵通常需要约5至6秒
* 靠近、互动、短对白或多阶段转折通常需要约7至9秒
* 多个动作、多人关系或重大情绪逆转通常需要约10至15秒

这些范围只用于规划。最终输出会给出一个准确时长，并把时长选择理由放在复制提示词外，提示词内部只保留模型需要执行的内容。

### 5. 让镜头参与表演

镜头运动必须服务于一个明确的情绪节点：

* 压抑悲伤适合平视近景，在呼吸停顿时缓慢靠近
* 失望适合三分之四近景，通过轻微后退增加人物周围的空白
* 克制愤怒适合正面近景或轻微低角度，在下颌收紧时推进并锁定
* 情绪麻木适合固定机位和更长停留
* 亲密心动适合柔和侧光，在双方目光接近相遇后轻微靠近

镜头完成情绪功能后立即停止，避免运镜继续抢夺表演注意力。

### 6. 两种输出模式

完整视频模式适用于模糊想法和独立视频需求。它会补全人物、场景、动机、时长、时间轴、镜头、光线、声音、一致性和负面约束。

表演片段模式适用于用户已经拥有场景、镜头或光线方案的情况。它只提供可以插入原提示词的面部、呼吸、身体和声音表演，不覆盖已有制作决定。

### 7. 输出前自检

Skill 会检查：

* 触发事件能否解释人物反应
* 情绪是否具有认知、抵抗、泄露、顶点和余韵
* 眼神、眉毛、嘴唇和下颌动作是否相互兼容
* 内在压力、外在幅度和自我控制是否能够区分
* 镜头与光线是否帮助观众看清微表情
* 人物身份、年龄、服装和环境是否保持一致
* 声音是否来自画面中真实存在的对象
* 提示词是否包含准确时长且没有未填写占位符

## 安装

### 方式一：安装到 Codex

macOS 或 Linux：

```bash
git clone https://github.com/chuanzhangAIshijie/chuanzhangbiaoqing.git \
  ~/.codex/skills/chuanzhangbiaoqing
```

Windows PowerShell：

```powershell
git clone https://github.com/chuanzhangAIshijie/chuanzhangbiaoqing.git `
  "$env:USERPROFILE\.codex\skills\chuanzhangbiaoqing"
```

## 设计理念

能够打动观众的人物情绪来自原因、过程和残留。眼神在什么时候停住，人物为什么移开视线，嘴角为何压住又松开，呼吸怎样暴露内心，镜头在哪个瞬间靠近，这些细节共同组成可信的表演。

这个 Skill 将真人表演中的动机分析、情绪递进和镜头调度固定成一套可复用流程，让 AI 在输出表情之前先理解人物正在经历什么。
